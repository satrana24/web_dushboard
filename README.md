# Музыкальный дашборд

## О проекте
Музыкальный дашборд — веб-приложение для поиска музыкальных исполнителей, прослушивания фрагментов треков и просмотра информации об артистах. Интерфейс позволяет собирать персональную панель из виджетов.

## Запуск локально
1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в терминале.
3. Запустите локальный сервер:

   ```bash
   python -m http.server 8000
   ```

4. Откройте в браузере http://localhost:8000.

## Основные функции JavaScript
- Добавление виджетов «Список дел», «Исполнитель» и «Об артисте».
- Поиск исполнителей и отображение списка треков с обложками.
- Прослушивание 30-секундных превью композиций.
- Случайный выбор исполнителя.
- Автоматическая загрузка статьи из Википедии для выбранного исполнителя.
- Отображение краткой информации об артисте и ссылки на статью.
- Обработка ошибок загрузки данных из внешних сервисов.

## Используемые API
- **iTunes Search API** — поиск музыкальных исполнителей и треков, получение обложек и ссылок на превью.
- **Wikipedia REST API и MediaWiki API** — поиск статей и получение информации об артистах.

## Использованные технологии
HTML5, CSS3, JavaScript (ES Modules), Fetch API.
